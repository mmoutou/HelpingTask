Analyses here use different packages in R and matlab. Here, code is provided to bring as-collected,
and/or as-per-package-output, data, to the format required by analysis toos. For example:

- json outputs with extension '.csv' produced by Jae Shin's task code are
  * brought in the matlab format needed for MentalizingSelfOther modeling.

  * brought in csv format needed for HiddenMarkovTrustStates modeling.
